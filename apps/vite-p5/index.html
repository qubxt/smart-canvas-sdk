What is WebGPU?

WebGPU is the web’s modern graphics and compute API, and the successor to WebGL. It’s designed around today’s native GPU APIs: Vulkan, Metal and Direct3D 12.

  • Compute shaders

    General-purpose GPU work, such as simulation, not only drawing.

  • Explicit pipelines

    State is declared up front rather than changed call by call, which leaves less work per draw.

  • WGSL

    A shading language built for the API, replacing GLSL.

What is p5.strands?

p5.strands lets you write shaders as JavaScript functions. It reads your function and generates shader code for the active renderer.

  • Hooks instead of boilerplate

    Change one stage, such as filterColor or worldInputs, and p5 supplies the rest.

  • Familiar p5 functions

    noise(), sin() and millis() work the way they do in a sketch.

  • Portable by default

    The same source targets GLSL on WebGL and WGSL on WebGPU.

Turning on WebGPU in p5

p5.js added its WebGPU renderer in version 2.2. It ships as an add-on, and createCanvas() must be awaited. 

import p5 from 'p5';
import webgpu from 'p5/webgpu';

p5.registerAddon(webgpu);

new p5((p) => {
  p.setup = async () => {
    await p.createCanvas(400, 400, p.WEBGPU);
  };
});
